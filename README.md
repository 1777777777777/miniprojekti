## Ohtu miniprojekti - Lähdeviitteiden hallintasovellus

Lähdeviitteiden hallintasovelluksen avulla käyttäjä voi hallita ja järjestellä projekteissaan käyttämiään lähdeviitteitä. Sovelluksen tarkoituksena on helpottaa lähdeviitteiden tallentamista, ylläpitämistä ja hyödyntämistä eri projekteissa.

Sovelluksessa käyttäjä voi lisätä ja tallentaa erityyppisiä lähdeviitteitä tietokantaan. Tallennettuja viitteitä voidaan liittää eri projekteihin, jolloin jokaisella projektilla on oma kokoelmansa käytettävistä lähdeviitteistä.

Sovelluksen avulla projektikohtaisista lähdeviitteistä voidaan myös muodostaa BibTeX-muotoinen tiedosto, jota voidaan hyödyntää esimerkiksi tieteellisissä teksteissä ja muissa dokumenteissa.

Sovelluksen keskeisiä ominaisuuksia ovat:
- Eri tyyppisten lähdeviitteiden lisääminen ja hallinta
- Lähdeviitteiden tallentaminen tietokantaan
- Projektien luominen ja hallinta
- Lähdeviitteiden liittäminen projekteihin
- Projektikohtaisten lähdeviitteiden vienti BibTeX-muotoiseen tiedostoon
